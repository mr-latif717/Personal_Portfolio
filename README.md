# Abdul Latif — Full Stack Developer Portfolio

A modern, responsive, and full-stack personal portfolio website built to showcase my skills, education, experience, projects, achievements, and technical journey.

The project includes a React-based frontend, a Node.js/Express backend, and a MySQL database for handling dynamic functionality such as contact form submissions.
